# 発表順ランダム選出ツール

発表候補者をランダムに選び、発表順を決めるブラウザー向けツールです。抽選中のルーレット演出、効果音、紙吹雪、連続して打ち上がる花火風エフェクトを楽しめます。

## 起動方法

1. `code_artifact.html` をブラウザーで開きます。
2. 「選出スタート！」を押して抽選します。

ビルドやパッケージのインストールは不要です。Tailwind CSS と Web フォントの読み込みに CDN を使用しているため、スタイルやフォントを利用するにはインターネット接続が必要です。

## 動作環境

- JavaScript と HTML Canvas に対応した最新のブラウザー（Google Chrome、Microsoft Edge、Mozilla Firefox、Safari など）
- Tailwind CSS と Web フォントを読み込むためのインターネット接続
- 効果音を利用する場合は、Web Audio API に対応したブラウザーと音声出力環境

PC・タブレット・スマートフォンのブラウザーで利用できます。ブラウザーの設定や端末の性能によって、アニメーションや音声の動作が異なる場合があります。

## 使い方

- **選出スタート！**：残っている候補者から1名を選び、発表順に追加します。
- **候補者編集**：候補者を5名入力して保存します。入力は1行に1名です。
- **やり直す**：現在の候補者で選出結果をリセットします。
- **新しい名前にチェンジ**：サンプルの日本姓から候補者5名を再生成します。

全員の順番が決まると、選出ボタンが無効になります。

## 演出とアクセシビリティ

- 抽選確定時に花火が複数回打ち上がり、放射状の光跡と紙吹雪が表示されます。
- 効果音は Web Audio API で生成します。ブラウザーの音声設定や操作環境によっては再生されないことがあります。
- OS の「視差効果を減らす」設定が有効な場合、花火と紙吹雪の量を減らし、画面フラッシュを表示しません。
